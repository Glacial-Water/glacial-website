# How to add a monthly Quality Certs report

You do this once a month. It takes about two minutes and needs no code.

1. Name the picture of the month's report like this: **YYYY-MM.jpg**. Year, a dash, two-digit month. Example: the October 2026 report is `2026-10.jpg`. (A `.png` picture also works.)
2. Go to the project page on github.com: https://github.com/Glacial-Water/glacial-website and sign in.
3. Click the folder called **reports**.
4. Click **Add file**, then **Upload files**.
5. Drag the picture in (or click "choose your files").
6. Scroll down and click the green **Commit changes** button.
7. Wait a few minutes. The website updates itself, and the new month appears at the top of the Quality Certs page, under its year.

Good to know:

- If the file is not named exactly like the example, it will not appear. Fix the name and upload again.
- Uploading a file with the same name replaces the old one for that month.
- To remove a report: open `reports`, click the file, click the three dots, choose **Delete file**, then **Commit changes**.
- The preview address is https://glacial-water.github.io/glacial-website/quality-certs/ (it will show once GitHub Pages is switched on, a one-time click described in the status document).
